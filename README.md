## Install and try

**Android:** Download the APK on your phone and open it. If prompted, allow installation from the browser or file manager you used, then install. You can revoke that source permission afterward. Do not disable Play Protect or other security protections; report any blocking warning.

**Windows:** Download and extract the ZIP, then open `MaiMaiWorld-Test-v0.6.exe`. No Godot editor is required. This build is unsigned; report any blocking publisher or security warning rather than disabling security protections.

## What’s new

- Character idle/fidget, walk/run and hover animation, with movement-facing poses.
- Radial menus follow selected furniture; characters can sit on chairs and couches.
- Reusable item triggers/actions, working lights, and ceiling lights/decorations.
- Addable windows with selectable views and larger carpet variants, including rectangles.
- Earlier room editing, family characters, Bedroom collection and touch fixes are retained.

## Test status

**Progress is not saved.** This is an early test, not the full game; arrangements reset on a fresh launch, and there is no multiplayer. Older builds remain available under All releases.

Automated checks passed for animation/motion, interactive items, window/rug placement, furniture, touch, UI and effect choices. Native Linux QA covered movement poses, seating/carrying, lights, ceiling-item deletion, tap-versus-drag behavior, window views and rug overlap.

Actual v0.6 Windows and Android runtime/device testing remains pending. Real Android touch, physical rotation and performance, native held-speed transitions and audio audibility are not yet fully verified.
