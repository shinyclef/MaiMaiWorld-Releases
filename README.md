## Install and try

**Android:** Download the APK on your phone and open it. If prompted, allow installation from the browser or file manager you used, then install. You can revoke that source permission afterward. Do not disable Play Protect or other security protections; report any blocking warning.

**Windows:** Download and extract the ZIP, then open `MaiMaiWorld-Test-v0.1.exe`. No Godot editor is required. This build is unsigned; report any blocking publisher or security warning rather than disabling security protections.

Drag the bear around the room, release it to increase the movement counter, and tap or click Reset to return it home.

## Test status

This is an early installation/input test, not the full game. No persistent saves or multiplayer; positions reset on a fresh launch. Native Linux room rendering, drag/release and Reset were verified, plus 15 automated interaction assertions. Actual Android and Windows runtime testing remains unverified.
